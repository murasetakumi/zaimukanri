# 📊 finboard — 1人法人向け財務ダッシュボード

Google スプレッドシート連携 + AIコンサルタント分析付きの財務管理ダッシュボードです。

## ✨ 機能

- **ログイン保護** — パスワードによる簡易アクセス制限
- **KPIカード** — 売上・粗利・粗利率・営業利益・営業利益率・経費・税負担
- **AIコンサルタント分析** — Claude APIで財務データを自動分析し、良かった点・改善点を表示
- **損益計算書（P/L）** — 月次・年間サマリー、売上構成の可視化
- **キャッシュフロー** — 累積残高・ランウェイ管理
- **節税シミュレーター** — 役員報酬・小規模企業共済・iDeCo・経営セーフティ共済の節税効果を計算
- **Google スプレッドシート連携** — Apps Script で自動データ同期

## 🚀 使い方

### 1. そのまま使う（GitHub Pages）

1. このリポジトリを fork
2. Settings → Pages → Source を `main` ブランチの `/` に設定
3. `https://あなたのID.github.io/リポジトリ名/` でアクセス

### 2. パスワードの変更

`index.html` の以下の箇所を編集：

```javascript
const CONFIG = {
  password: 'demo1234',  // ← ここを変更
  ...
};
```

> ⚠️ **注意**: フロントエンドのみのパスワード保護です。GitHubリポジトリを公開にするとコードからパスワードが分かります。財務データは必ずGoogle スプレッドシート側に保存し、`index.html` にハードコードしないでください。

### 3. Anthropic API キーの設定（AIアドバイス機能）

AIコンサルタント機能を使うには Anthropic API キーが必要です。

**開発環境（ローカル）の場合:**
```html
<!-- index.html の fetch ヘッダーに追加 -->
'x-api-key': 'sk-ant-...',
'anthropic-version': '2023-06-01',
'anthropic-dangerous-direct-browser-access': 'true',
```

**本番環境:** セキュリティのため、APIキーはサーバーサイド（Vercel/Cloudflare Workers等）で管理することを推奨します。

### 4. Google スプレッドシート連携

ダッシュボード右上の「📊 スプレッドシート連携」ボタンから手順を確認できます。

スプレッドシートの形式：
| A列（月） | B列（売上・万円） | C列（仕入・原価・万円） | D列（経費・万円） |
|-----------|-----------------|----------------------|----------------|
| 1 | 80 | 20 | 45 |
| 2 | 75 | 18 | 42 |
| ... | ... | ... | ... |

## 🔒 セキュリティについて

このダッシュボードはフロントエンドのみで動作します。

- パスワードはコード内に含まれるため、リポジトリを**プライベート**にすることを強く推奨します
- GitHub Pages はプライベートリポジトリでも有料プランで利用可能です
- 完全なセキュリティが必要な場合は、Vercel / Netlify + 環境変数でのバックエンド認証を検討してください

## 🛠 カスタマイズ

- `D` オブジェクトのサンプルデータを実際の数値に変更
- `D.revBreakdown` でサービス別売上構成を設定
- `D.expCats` で経費カテゴリを変更
