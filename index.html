📊 スプレッドシート連携設定

「単年度事業計画実績値」シートのデータを自動で読み込みます。Apps Script を一度設定するだけでOKです。

1スプレッドシートを開き、拡張機能 → Apps Script を選択

2下のコードを全選択して貼り付け、保存（Cmd+S）

function doGet() { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName("単年度事業計画実績値"); const data = sheet.getDataRange().getValues(); const COL_START = 4; const MONTHS = 12; function getRow(rowIdx) { if (rowIdx >= data.length) return Array(MONTHS).fill(0); return data[rowIdx].slice(COL_START, COL_START + MONTHS) .map(v => typeof v === 'number' ? v : (parseFloat(v) || 0)); } // 売上明細（行4〜17） const revItems = []; for (let r = 3; r <= 16; r++) { if (r >= data.length) break; const row = data[r]; const name = (row[1] || row[2] || '').toString().trim(); if (!name) continue; const vals = row.slice(COL_START, COL_START + MONTHS) .map(v => typeof v === 'number' ? v : (parseFloat(v) || 0)); if (vals.some(v => v !== 0)) revItems.push({ name, values: vals }); } // 原価明細（行19〜28） const cogItems = []; for (let r = 18; r <= 27; r++) { if (r >= data.length) break; const row = data[r]; const name = (row[1] || row[2] || '').toString().trim(); if (!name) continue; const vals = row.slice(COL_START, COL_START + MONTHS) .map(v => typeof v === 'number' ? v : (parseFloat(v) || 0)); if (vals.some(v => v !== 0)) cogItems.push({ name, values: vals }); } const result = { monthLabels: data[2] ? data[2].slice(COL_START, COL_START + MONTHS) .map(v => v.toString()) : [], revTotal: getRow(17), cogsTotal: getRow(28), grossProfit: getRow(30), revItems, cogItems, }; return ContentService .createTextOutput(JSON.stringify(result)) .setMimeType(ContentService.MimeType.JSON); }

3デプロイ → 新しいデプロイ → 種類「ウェブアプリ」、アクセス「全員」でデプロイ

4発行されたURLを貼り付けて「読み込む」をクリック

※ URLはlocalStorageに保存。対象シート：「単年度事業計画実績値」
